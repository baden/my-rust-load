# Опис
file_upload_server - це сервер на Rust, який використовує бібліотеки warp та tokio для обробки запитів на завантаження та збереження файлів.

# Вимоги
- Rust (версія 1.56 або новіша)
- Cargo

# Налаштування
1. Клонуйте репозиторій:
   ```
   git clone <URL_репозиторію>
   cd file_upload_server
   ```

2. Встановіть залежності:
   ```
   cargo build
   ```

# Запуск
Для запуску сервера використовуйте команду:
```
cargo run
```

Сервер буде запущено на `http://localhost:3030`.

# Використання
- Для завантаження файлів надішліть POST запит на `/upload` з файлом у тілі запиту.
- Для завантаження файлів надішліть GET запит на `/download/{filename}`.
